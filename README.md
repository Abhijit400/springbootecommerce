# 🛍️ E-commerce apis

## 📌 Project Summary
An e-commerce application inspired by Myntra. This project demonstrates api development in Spring Boot for the backend. It provides a seamless shopping experience including product browsing, cart management, authentication, and order processing.

---

## 🚀 Features

- 👕 Browse products by category
- 🔍 Search & filter products
- 🛒 Add to cart / remove from cart
- ❤️ Wishlist functionality
- 🔐 User authentication (Login / Signup)
- 💳 Checkout flow
- 📦 Order management
- 📱 Responsive UI

---

## 🏗️ Tech Stack

### Frontend
- React.js
- Redux / Context API
- HTML, CSS, Tailwind / Bootstrap

### Backend
- Java
- Spring Boot
- REST APIs
- Spring Security (JWT)

### Database
- PostgreSQL / MySQL

---


## 🔑 Environment Variables

DB_URL=jdbc:postgresql://localhost:5432/myntra  
DB_USERNAME=your_username  
DB_PASSWORD=your_password  
JWT_SECRET=your_secret_key

## 📡 API Endpoints

GET /products  
GET /products/{id}  
POST /auth/login  
POST /cart/add  
GET /orders
